# Changelog

All notable changes to Easel are documented here. The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to
[Semantic Versioning](https://semver.org/spec/v2.0.0.html). TestFlight's What to Test for each
version comes from its section (`task testflight:notes`).

## [0.1.3] - 2026-11-10

### Changed

- A fresh build reaches TestFlight on the 1st of every month, so Easel never expires, even when nothing has changed.

## [0.1.2] - 2026-11-10

### Changed

- Easel is now open source, under the MIT licence.
- New versions are built and sent to TestFlight by GitHub, so updates arrive after every change.

## [0.1.1] - 2026-11-10

### Changed

- New versions now arrive in TestFlight automatically, with these notes, after every change.

## [0.1.0] - 2026-11-10

### Added

- Home, Search and My Easel, with a page for every video and series.
- Big player controls on the iPad; a remote with very large buttons when the video is on the TV.
- Bookmarks with notes, favourites, resume where you stopped, and downloads for watching offline.
